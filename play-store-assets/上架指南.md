## ⚠️ 先看这个：政策风险（很重要）

X / Twitter 视频下载类应用，Google Play 经常以「**侵犯知识产权 / 帮助下载受版权保护内容**」为由**拒绝上架或事后下架**。应用商店里大量同类应用已被移除。

所以要有心理准备：
- 上架**不保证通过**，可能被拒。
- 即使通过，**后续也可能被下架**。
- 这不是你填得对不对的问题，是这一类应用的固有风险。

建议：心态放平试一次；若被拒，GitHub 分发（releases）依然是稳定可靠的渠道。

## 一、准备：Google Play 开发者账号

- 地址：https://play.google.com/console
- 费用：一次性注册费 **$25 美元**
- 需要：Google 账号 + 开启两步验证 + 完成身份/付款方式验证
- 新账号可能需要几天审核，且部分功能（如正式版发布）要求账号有一定测试人数门槛（新政策：新个人账号需 20 人封闭测试 14 天才能申请正式版，见第六条）。

## 二、密钥与签名（你最关心的部分）

Google Play 涉及**两把钥匙**，别搞混：

| 钥匙 | 作用 | 谁保管 |
|------|------|--------|
| **应用签名密钥**（App Signing Key） | 给最终分发给用户的 APK 签名 | **Google**（Play 应用签名，免费托管） |
| **上传密钥**（Upload Key） | 你上传 AAB 前给它签名 | **你**（就是项目里的 `my-upload-key.jks`） |

### 具体流程
1. 创建应用时，加入「**Play 应用签名（Play App Signing）**」——新应用**强制**，Google 会自动生成并保管应用签名密钥，你无需提供。
2. 用项目里已有的 `my-upload-key.jks` 给 AAB 签名后上传（我已构建好签名 AAB，见文末）。
3. **务必备份**：`my-upload-key.jks` 和 `keystore.properties` 拷贝到网盘/密码管理器。丢了上传密钥虽然能找 Google 重置，但麻烦。

### 关于和 GitHub 版签名是否一致（二选一）

- 你在 GitHub 发的 APK 是用 `my-upload-key.jks` 直接签的。
- Play 版默认由 Google 用**新的**应用签名密钥签 → 两者签名**不同** → 已装 GitHub 版的用户**无法直接覆盖更新**到 Play 版（要先卸载旧版）。

**两个选择：**

- **A. 简单（推荐小项目）**：接受签名不同。Play 新用户直接装，GitHub 老用户先卸载再装。啥都不用多做。
- **B. 签名一致（想留住老用户无缝更新）**：加入 Play 应用签名时选「使用自己的应用签名密钥」，把 `my-upload-key.jks` 作为应用签名密钥上传给 Google（需用 Google 的 **PEPK 工具** 把密钥导出加密后上传）。这样 GitHub 版和 Play 版签名相同，可互相覆盖更新。
  - 代价：要把你的私钥交给 Google，且操作稍技术。
  - 本项目用户量小，**建议选 A**，省事。

### 1. 商品详情（Store listing）

**应用名称**（≤30 字符）
```
X-Down – X视频下载器
```

**简短说明**（≤80 字符）
```
粘贴链接，一键无损下载 X / Twitter 视频。多清晰度、断点续传、免费无广告。
```

**完整说明**（≤4000 字符）
```
X-Down 是一款简洁干净的 X（前 Twitter）视频下载器。复制推文链接，即可一键解析并无损保存视频到手机本地。

【核心功能】
• 一键解析：粘贴 X 推文链接即刻解析，支持剪贴板自动识别
• 多清晰度：480P 到 1080P 及以上，按需选择，无损保存原始画质
• 多视频拆分：一个帖子多个视频自动拆分为独立卡片，逐视频下载
• 断点续传：支持暂停、继续与断点续传，应用关闭后任务不丢失
• 本地归档：视频统一保存至本地并同步系统相册，支持离线播放
• 作者排行：自动统计每位作者的下载视频数，常看作者一目了然

【我们的承诺】
• 完全免费，无任何广告
• 无需注册登录，打开即用
• 不收集任何用户数据
• 代码开源，公开透明

【开源地址】
https://github.com/alosir/X-Down

【说明】
本应用仅供学习交流使用，请遵守相关平台的使用条款与版权规定，勿用于侵犯他人权益的用途。
```

- 标签：视频下载、工具

## 四、内容分级（IARC 问卷）

填一份问卷，按实回答：
- 无暴力、无色情、无赌博 → 通常为「所有人 / Everyone」或「青少年」
- 有一题涉及「用户能否接触网络/用户生成内容」，选「是」（因为可下载网络视频），按实作答即可。

## 五、数据安全（Data safety）

按 X-Down 实际情况填，基本可全部选「不收集 / 不分享」：
- **是否收集用户数据**：否（应用不主动收集、不分享任何个人数据）
- 应用会联网下载视频，但**数据不传回开发者服务器**，无账号体系。

## 六、目标受众与广告

- **目标受众**：建议选 **18 岁以上**（可下载任意网络视频，内容不可控，选成人更稳妥，也更易过审）
- **是否含广告**：**否**

## 七、上传 AAB 并发布

- 已构建好的签名 AAB：`app/build/outputs/bundle/release/app-release.aab`
- 路径：Play Console → 你的应用 → **发布 → 正式版 / 封闭测试 / 内部测试** → 创建版本 → 上传该 AAB
- **强烈建议**：先走「**封闭测试**」或「**内部测试**」，跑通后再转正式版。
- 新个人开发者账号注意：Google 新规要求正式版发布前需有 **20 名测试者参与封闭测试满 14 天**。内部/封闭测试没有这个硬门槛，可先用测试渠道。
- 版本说明（What's new）可抄 GitHub Release 的更新内容。
